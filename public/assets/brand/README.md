# Stephen Clark identity assets

SC monogram and name lockups for the portfolio.

## Files

| File                                                         | Use                                  |
| ------------------------------------------------------------ | ------------------------------------ |
| `stephen-clark-logo-forest.svg`                              | Horizontal logo in forest green      |
| `stephen-clark-logo-black.svg`                               | Horizontal logo in black             |
| `stephen-clark-logo-white.svg`                               | Horizontal logo for dark backgrounds |
| `sc-mark-forest.svg`                                         | Standalone forest monogram           |
| `sc-mark-black.svg`, `sc-mark-white.svg`, `sc-mark-lime.svg` | One-color monograms                  |
| `sc-mark-micro.svg`                                          | Square-ended variant for small sizes |
| `favicon.svg`                                                | Forest and lime browser icon         |
| `favicon-16-master.svg`, `favicon-16.png`                    | Simplified 16-pixel icon             |
| `favicon-32.png`, `favicon-48.png`                           | Standard browser icon sizes          |
| `apple-touch-icon.svg`, `apple-touch-icon.png`               | 180-pixel touch icon                 |
| `avatar.svg`, `avatar.png`                                   | 512-pixel profile image              |

PNG versions of several logos and marks are also included. SVG lettering is outlined and does not require a font at runtime. The portfolio uses `sc-mark-black.svg` for its footer and browser icon.

## Usage

- Preserve proportions, spacing, and a clear area of at least one stroke thickness around the symbol.
- Use the horizontal logo at 200 CSS pixels or wider. Use the standalone mark at 32 pixels or wider, the micro variant below 32 pixels, and the supplied 16-pixel icon at its intended size.
- Use black on light backgrounds and white on dark backgrounds. Forest `#20251F` and lime `#D5EF91` are additional color variants.
- Keep both letters the same color. Avoid added outlines, shadows, or gradients.
- Give a logo home link the accessible name “Stephen Clark home.” When the link already has that name, use empty alt text on its image.
